# SSIM is computed at 50 dpi in gray on 8x8 windows (stride 4), skipping windows

#
# Rules: a value is the measured SSIM rounded down to the hundredth, minus 0.01
# (rasteriser noise across platforms). It records where we are, not where we want
# to be: raise it when a change improves a page, never lower it to make a change
# pass. Values below 0.90 carry the reason.
#
# What lowers SSIM even when the layout matches: QtWebKit positions glyphs with
# fractional advances while our layout snaps each "space + word" segment to whole
# pixels, so text shifts by up to half a pixel per word; antialiasing differs.
